# Sara Beauty Artistry

A bilingual Arabic/English static demo website for a luxury bridal makeup artist brand.

## Render Deployment

This repository includes a `render.yaml` Blueprint for a Render Static Site.

- Service type: Static Site
- Publish path: `.`
- Build command: none
- Entry point: `index.html`

Deploy from Render by creating a new Blueprint from this repository:

`https://github.com/iPaide/Sarah-Makeup`
